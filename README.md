Vinheria Agnello

Projeto de um site institucional para a Vinheria Agnello, desenvolvido como parte do CP1 da FIAP.

Sobre o projeto

O site apresenta a Vinheria Agnello e informações sobre o mundo dos vinhos, incluindo sua história, tipos de vinho, uvas, armazenamento e harmonização.

O projeto foi desenvolvido com foco na prática dos conhecimentos básicos de desenvolvimento web.
