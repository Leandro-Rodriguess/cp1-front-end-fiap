# Vinheria Agnello

Projeto de um site institucional para a **Vinheria Agnello**, desenvolvido como parte do **CP1 da FIAP**.

## Sobre o projeto

O site apresenta a Vinheria Agnello e informações sobre o mundo dos vinhos.

## Tecnologias utilizadas

- HTML5
- CSS3

## Conteúdo do site

- Início
- Nossa História
- Vinhos
- Armazenamento
- Uvas
